Assessment
  • Initial access → execution pivot. An Office process spawning powershell.exe -enc almost always means a weaponised document ran a macro. Benign automation rarely base64-encodes its command line.
  • High-value target. WIN-DC01 is a domain controller; SYSTEM-level code execution here is materially worse than on a workstation.
  • Decoded payload is suspicious. The -enc blob decodes to a download cradle reaching an external host — consistent with second-stage retrieval.
