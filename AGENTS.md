## Configuration boundary

`.env` holds two kinds of key and nothing else:

- **Structural secrets** (2): `ION_DB_PASSWORD` and `ION_ADMIN_PASSWORD`.
  Compose interpolates `ION_DB_PASSWORD` into `POSTGRES_PASSWORD` and
  `ION_DATABASE_URL` before any ION process exists, and `ION_ADMIN_PASSWORD` is
  read from `os.environ` in `web/server.py` (there is no `Config` field for it).
  Removing either one stops the stack from starting.
- **Bootstrap** (6): `ION_VERSION`, `ION_DATA_DIR`, `ION_HOST`, `ION_PORT`,
  `ION_WORKERS`, `ION_LOG_LEVEL`. These are read before the app can consult its
  own settings, so they cannot live in `config.json`. `ION_DATA_DIR` locates
  `config.json` itself.

Everything else, including the integration secrets (Elasticsearch, Kibana,
GitLab, OpenCTI, Arkime, TIDE), is managed in the settings UI and stored in
`$ION_DATA_DIR/.ion/config.json`. Secrets cannot be kept out of that file:
`Config.to_file` serialises the whole in-memory config on every section save.
Environment variables still outrank that file, so a key reappearing in `.env`
silently overrides the UI. Settings shows such fields read-only with a "set by
environment" badge; `tests/test_env_boundary.py` keeps the shipped templates
honest. The key sets are `BOOTSTRAP_ENV_KEYS` and `ENV_FIELD_MAP` in
`src/ion/core/config.py`.

## Finding a route

`docs/ROUTE_MAP.md` is generated by `tools/route_map.py` and lists every
route the application serves, with its permission, the handler's file and
line, the template it renders and the templates or scripts that call it.
Grep it before grepping the source: three things about ION's routing are
invisible to a reader searching for a path.

- `server.py` registers 19 canonical path aliases *after* the routers are
  mounted. `/api/alerts/triage/batch` is a real route that appears in no
  decorator, and the alerts page depends on it. Searching the decorators
  finds nothing, and the obvious conclusion is wrong.
- A router's prefix is applied at `include_router`, so the path in a
  decorator is never the path a caller uses.
- A permission gate can sit on the decorator, the signature or the router.
  Only the built dependency tree has all three.

Regenerate with `python tools/route_map.py` after adding or moving a
route; `tests/test_route_references_resolve.py` fails if the file is stale,
and also fails if any `/api` or `/ui` URL a template or script names has no
route behind it. That check found the alerts page posting Translate to
`/api/ai/translate`, which nothing has ever served.
